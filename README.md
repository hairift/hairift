## 👨‍💻 Tentang Saya

<img align="right" alt="Coding GIF" width="380" src="https://media.giphy.com/media/qgQUggAC3Pfv687qPC/giphy.gif"/>

Saya adalah mahasiswa **Teknik Informatika** di **Universitas Catur Insan Cendekia (UCIC)** yang penuh semangat dalam dunia teknologi.

🎯 **Spesialisasi Saya:**
- 🌐 **Web Development** — dari frontend hingga backend
- 📱 **Mobile Development** — aplikasi Android & iOS dengan Flutter
- 🔧 **IoT Engineering** — sistem embedded dengan ESP32 & Arduino
- 🤖 **Artificial Intelligence** — eksplorasi ML & data processing

💡 Saya percaya bahwa teknologi terbaik adalah teknologi yang benar-benar **menyelesaikan masalah nyata**. Saya selalu antusias belajar stack baru dan membangun solusi yang efisien, intuitif, dan berdampak.

🤝 Mari terhubung dan ciptakan inovasi bersama!
